## Questions about this page

Every `###` heading becomes a collapsed item. With only `##` headings, those become the items.

### How do I mark a figure as unknown?

Write **Unknown** or **Not yet measured** as the value in a stats section. The figure is shown muted, with a dashed line, so nobody mistakes it for a measurement.

### How do I colour a card by theme?

Add a line block straight under the card heading with `theme: 3`. The card gets a coloured top edge and a theme label.

### Can I use these classes without Markdown?

date: Version 1.1

Yes. All classes in `durf-site.css` work in hand-written HTML too.
